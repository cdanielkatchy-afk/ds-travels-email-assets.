# DS Travels email signature

Team link: https://thepolymathconsults-afk.github.io/ds-travels-email-assets./

- `index.html` is the DS Travels Signature Studio (team signature generator).
- `assets/` holds the public images every signature loads: logos, icons and the panel pattern.
- `birthday/` is the DS Travels Birthday Studio (customer birthday flyer generator).

Do not rename or move files in `assets/`: emails already sent load their images from these exact addresses.
