Install it

Gmail (web)
  1. Click Copy signature above.
  2. In Gmail open Settings (gear) › See all settings › General › Signature.
  3. Click Create new, name it "DS Travels", click into the box and paste (Ctrl+V or Cmd+V).
  4. Set it as default for new emails and replies, then Save changes at the bottom.
Gmail with the downloaded image
  1. Click Download as image and save the PNG to your computer.
  2. In Gmail open Settings (gear) › See all settings › General › Signature › Create new.
  3. Click the Insert image icon in the signature toolbar, choose Upload, and select your PNG.
  4. Click the image and choose Original size so it shows at 600 pixels wide.
  5. Optional: select the image, click the link icon and enter the DS Travels Instagram page, so a tap on the signature opens it.
  6. Set it as default for new emails and replies, then Save changes.
Outlook (web and new Outlook)
  1. Click Copy signature.
  2. Open Settings › Accounts › Signatures › New signature.
  3. Paste into the editor, choose it as default for new messages and replies, then Save.
Outlook (classic desktop)
  1. Click Copy signature.
  2. Go to File › Options › Mail › Signatures › New.
  3. Paste into the edit box, pick defaults on the right, then OK.
Apple Mail and iPhone
  1. Mac: Mail › Settings › Signatures › +, untick "Always match my default message font", paste.
  2. iPhone: send yourself an email containing the signature, then copy it into Settings › Mail › Signature.

Brand team settings

Every signature loads its images from the public DS Travels GitHub folder, so recipients always see them. Change this only if the images move to another public address, such as the DS Travels website.
